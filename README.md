# Prodigy Racing IT Decoder

这是一个专门用于解码 Prodigy Racing 游戏中 `.IT` 音乐文件的工具。

## 简单说明！！(*^_^*)

Prodigy Racing 游戏中的背景音乐文件使用了非标准的 IT 格式，导致常规播放器（如 OpenMPT, VLC）无法识别。项目提供了一个 Python 脚本将这些文件批量还原为标准的、可播放的 IT 格式文件。

## 使用方法

1. **环境要求**：确保您的系统已安装 [Python 3](https://www.python.org/)。()
2. **文件准备**：将游戏文件目录中的 `MOD` 文件夹内的`IT`文件放入与脚本相同的目录下。
3. **运行脚本**：

   ```bash
   python decode_it.py
   ```

4. **查看结果**：脚本运行完毕后，目录下会通过解码生成新的 `.IT` 文件，可以直接使用IT播放器播放这些`.IT`文件啦。

## 解码原理~ Σ(っ °Д °;)っ

### 分析
首先通过对比文件头数据，发现该游戏的 IT 文件采用了简单的 **字节偏移（ Byte Offset）** 加密！

- **标准 IT 文件头**：`IMPM` (HEX: `49 4D 50 4D`)
- **加密文件头**：HEX `B8 BC BF BC`

### 解密算法
加密过程是对每个字节增加了 `0x6F`。因此，解密算法为：

$$
\text{DecryptedByte} = (\text{EncryptedByte} - 0\text{x}6F) \pmod{256}
$$

### 实现逻辑
脚本会读取文件的前 4 个字节：
1. 如果是 `IMPM`，则认为是原始文件，跳过。
2. 如果尝试解密后等于 `IMPM`，则认为是加密文件，执行全量解密。
3. 其他情况视为未知格式，予以忽略。
